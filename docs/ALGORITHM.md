# 点云估计、噪声模型与训练差异

## 数据的几何含义

所有运行时四元数使用 xyzw。`R_WB` 将机体向量变到重力对齐世界系，`R_BL,t_BL` 是雷达相对训练 base 的外参：

```
p_B = R_BL p_L + t_BL
p_W = R_WB(t) p_B + t_WB(t)
p_Y = R_z(yaw_query)^T (p_W - t_WB_query)
h_i = clip(z_base_query - z_terrain_i - 0.5, -1, 1)
```

Z 使用重力竖直方向，而不是倾斜机体的 Z。先去掉已标定的自体区域、非有限点和超量程点，再做坐标变换。不会拟合一个大平面后把地面全部删除——地面本身正是策略所需数据。

| 坐标系 | 原点/轴向 | 来源 |
|---|---|---|
| LiDAR | 驱动定义，必须通过实测外参映射 | PointCloud2 header.frame_id |
| base | 训练 base_link；X 前、Y 左、Z 上；角度右手正方向 | 机器人几何模型/位姿适配 |
| world/odom | 固定局部原点、Z 竖直向上 | 可靠姿态与里程计 |
| base_yaw | 原点随 base 平移，XY 只跟随 yaw，Z 始终竖直 | 输出网格 |

没有隐藏镜像、轴交换、frame 重命名或额外高度偏移。坐标适配只在显式外参和 Pose 入口做一次。

## 估计流程

1. PointCloud2 读取支持 float32/float64 XYZ、大小端、非连续字段、行填充；超点数/字节预算拒绝。QoS depth=1、只保留一个最新待处理扫描。
2. 位姿缓冲按时间插值：平移线性、四元数 SLERP。逐点时间可用时以短时间桶去畸变；只使用有前后样本包围的时间，不外推。缺逐点时间时使用整帧位姿，额外计入未去畸变误差。
3. 每次扫描建立一个固定在采集位置/yaw 的小网格。每格只使用本格的点；先检查可支持的多层结构，再用 median/MAD 去离群点，做三次 Huber 加权局部平面拟合。
4. 必须有足够点数和二维空间分布，不能只是一个竖直立面或一条线；斜率、拟合残差与外推距离过大时失效。两层均有足够支持时标未知；不会把两个台阶高度平均成斜坡。
5. 查询时把当前网格中心映射到原采集网格，使用最近格保留不连续性。地图固定锚定在原采集坐标，避免连续原地滚动取整导致累积漂移。未知区域没有填洞或跨层双线性插值。
6. v0 仅保留最新扫描；v1 遍历有限时间窗口里的扫描，每格选择最新有效来源。当前明确检测到的多层/垂直歧义会使旧格失效；单纯遮挡/未采到点可在寿命内保留旧来源。

这是一张有限范围的 2.5D 支撑表面图。悬空顶板、密集草丛、透明/镜面材料、运动物体和复杂多层结构不保证能正确重建；没有语义/可通行性推理。孤立坏回波可抑制，成片一致的错误回波不能仅靠局部几何识别。不能把“置信度分数高”解释为“地面一定安全”。

## 数学噪声模型

采用“独立测量误差 + 扫描共享误差 + 位姿误差 + 时间误差”的分解。工程思路与 [ANYbotics/ETH 的机器人中心高程图不确定性建模](https://github.com/ANYbotics/elevation_mapping)一致，但这里是专为 187 点学生观测编写的有界 CPU 实现，没有移植该项目的全局映射器，也不是论文算法的完整复现。

对距离 r 的回波，保守的竖直测量方差上界：

```
sigma_range(r) = a + b*r²
sigma_sensor² <= sigma_range(r)² + (r*sigma_angle)²
```

两个距离参数和角度误差要通过真机静态平面数据标定。该公式使用竖直投影上界，未依赖未经确认的激光束方向/环号。

每格的有效样本数限制为 `min(max_effective_samples, (sum w)² / sum(w²))`，防止同一扫描的相关点被当作数千个独立观测，产生虚假的极高置信度。基础方差包含：

```
V_capture = mean(V_sensor)/n_eff
            + robust_residual_rms²
            + shared_height_bias_std²
            + correlated_height_std²
            + pose_z_variance
            + roll_pitch_projection_variance
            + local_slope_xy_variance
            + unresolved_motion_std²
```

共享偏置、相关误差和拟合残差不随点数无限减小。姿态使用测得点坐标传播，不读取真实地形误差：令 `b=R_WBᵀ(p_W−t_WB)`，`e=R_WB` 的第三行，则

```
J_roll  = e_z*b_y - e_y*b_z
J_pitch = e_x*b_z - e_z*b_x
V_tilt  = mean(J_roll²)*V_roll + mean(J_pitch²)*V_pitch
```

ROS 协方差需要有限、对称、半正定。未知的零协方差采用配置下限，不当作完美姿态。位置与姿态块取最大特征值作为保守界；交叉项以范数增加保守余量。Pose API 中六个对角量的明确约定是世界系位置方差和机体系小角度方差。

地图查询时间与采集时间不同且缺少跨时刻协方差时，垂直相对误差采用上界 `(sigma_z_capture+sigma_z_query)²`；采集方差已计入，只加剩余项。它偏保守，避免定位 Z 退化时仍输出高置信度。

v1 进一步使用相邻**有效**格的最大单边高程差估计 gx、gy 和台阶边缘差 `d_edge`，与训练实现一致：

```
J_yaw = -y*gx + x*gy
V_edge = (gx²+gy²)*V_xy + J_yaw²*V_yaw
         + d_edge² * clip(2*(sigma_xy+radius*sigma_yaw)/resolution, 0, 1)
V_effective = V_capture/query + V_edge + age*variance_growth_per_s
c = validity * exp(-age/tau) / (1 + V_effective/reference_std²)
```

局部平面误差与栅格重采样/边缘歧义分别建模；这是保守的工程上界，未宣称是最小方差后验或标定概率。v0 同样使用实测基础质量与时间退化，但不强行模拟 v1 特有的边缘质量表达。

未去畸变误差上界按 `(speed + max_range*angular_speed)*scan_duration/sqrt(12)` 估计；去畸变后使用时间桶宽度作为残余时长。速度取里程计 twist、相邻位姿速度与配置下限的最大值；IMU 模式平移采用配置运动上界。它假设扫描区间内速度有界，不能替代真实的扫描时间字段或高速动态校核。

**几何锚点时间和观测年龄分开。** 有逐点时间时，每个有效格使用实际参与最终稳健平面拟合的支持点的最早采集时间做保守过期；不能用别格、远处或已排除离群点的时间给该格计龄，也不能用末点或收件时间刷新旧支持。只有支持点的最晚时间也不晚于查询时刻，该格才能使用。无逐点时间且 header 是扫描结束时，按 header−scan_duration 计年龄。重复发布和地图重新查询不会刷新点龄。AOS 另外增加网络传输时间，在同一质量公式下衰减，超过地图或对齐寿命后失效。

多层/墙面等歧义保留实际支持时间区间；最新矛盾证据屏蔽更旧高度，直到被否定的旧观测按原寿命全部过期。该屏障只产生未知，不产生可信高度，避免歧义包过期后旧平地复活。整个 patch 只有在所有有效格和屏障都失效后才移除。地图寿命、有效覆盖和时间阈值不因此增大。

融合扫描中已经过期的点不能继续给新平面提供支持。处理开始及去畸变结束时读取实际 ROS 时钟，按原 `max_map_age_s` 丢弃已过期回波，再从剩余点重新计算点数、空间分布、稳健拟合和方差；传输数据不改。所有仍新鲜的层都保留用于歧义判定，不通过选择“最新可拟合的一层”获得覆盖。计算期间仍可能有点过期，发布和 AOS 接收时继续逐格拒绝；处理开始的检查不代替最终时效检查。稳健拟合的行中位数使用与原 NumPy 中位数等价的排序计算，避免旧版 NumPy 的 masked-array 开销，不改变数学结果。

去畸变前可裁掉不可能进入最终 ROI 的远点：旋转保持机体坐标点的范数，ROI 外接球半径加扫描区间内机体相对锚点的最大实际平移，可由线性位姿插值各段端点包络。球外点按反三角不等式不能落入最终 ROI。外参先应用到点，平移包络来自实际位姿，不能只用配置速度乘时长。裁剪不降采样目标区内数据，去畸变质量仍覆盖实际保留点所使用的插值位姿。

## v0/v1 训练差异，不能只看名称

| 项目 | v0 源码 | v1 源码 | 实机处理 |
|---|---|---|---|
| 本体历史 | 无 | 可选，默认 1；4 帧时追加 171 维 | 按权重 sidecar 决定 |
| 地图保留 | 最新送达整包 | 每格最新已送达有效观测 | 分别实现 |
| FOV | 原始训练 surrogate 不做光束/自遮挡；MuJoCo adapter 可额外裁 FOV | 前后 135° 合成 FOV、范围、地形视线遮挡 | 以真实回波可见性为准，不补模拟可见点 |
| 时间 | 更新周期、随机延迟随 level 缩放 | 固定硬件周期/延迟，加 jitter；level=0 仍存在时序 | 用真实 header/点时间，绝不按 level 改时钟 |
| 高度 | 随机噪声、整包偏置 | 另有空间相关噪声、地图伪影 | 测距模型、共享误差下限、实测残差 |
| 位姿 | XY/yaw 固定偏置，置信度未完整传播 | XY/yaw 漂移，roll/pitch 与重力观测耦合，梯度及边缘传播 | 标定外参和实际位姿，显式传播方差 |
| 丢失 | 点、块、整包 dropout | 另有 burst blackout，按格记忆 | 实际缺测/时间过期，无随机丢包 |
| 质量估计误差 | 确定质量公式 | 加 log-normal 误差及偶发过度自信 | 使用确定可审计质量估计，不制造过度自信 |
| 本体/动作 | v0 基础本体通道；MuJoCo extras 可另加噪声/延迟 | 本体噪声和一步动作延迟，previous action 为 issued action | 真实测量，不重复加噪声/人工动作延迟 |
| severity | level 默认 0.25，具体看 checkpoint | 默认 0.5 加 clean/nominal/stress mixture 与课程 | 默认值不是传感器实测参数 |

**`student-v0` / `student-v1` 噪声预设名与策略版本是两个不同维度。** `noise_profiles.py` 中 `realistic` 是 `student-v0` 别名，`train` 是 `student-v1` 别名；选择哪份策略并不能唯一确定实际训练噪声。最终应读取该 checkpoint/export 的 provenance.perception 和 observation_contract。当前只有用户之后指定的权重才是部署权威。

在真实雷达上添加训练时随机高程偏置、丢帧或动作延迟，会把真实噪声再叠加一次，通常不应如此。本实现“匹配”的是输入语义、质量公式、记忆方式和对现实不确定性的表达；它不声称真实误差分布已经等同于训练分布。

## 现场标定建议

1. 对已知平面，在多个距离/反射材料和俯仰下静态采集。用独立测量的平面估算偏差、MAD、空间相关性；分离静态共享偏置与逐点散布。
2. 固定场景运动机器人，比较不同角速度/线速度、去畸变开关、里程计重投影误差。时钟误差可伪装成外参或地图噪声，要先查时序。
3. 记录实际遮挡、丢帧长度、格点年龄、有效覆盖、CPU p95 和发布间隔，与最终模型训练 provenance 对照。缺少真值时不要把拟合残差当真实高度误差。
4. 在独立于拟合数据的真实记录上验证：按置信度分桶观察误差是否随置信度提高而减小；若不单调，修质量模型或数据链路。默认 reference_std 只控制映射尺度，不代表已经完成概率校准。

这些真实数据尚未提供，因此参数是待标定的工程起点；本轮只验证数学/协议对齐和合成数据表现。


## 实机融合扫描时间（10 月 15 日修正）

AOS 融合点云的 header 保持原始扫描锚点，每点 `timestamp` 保持绝对采集秒。实测扫描跨度更新在部署配置的 `scan_duration_s`，不修改原厂雷达或 LIO 的输入时间。传输 freshness 根据已校验的末点采集时间判定，未来点、非有限点时间、超出声明跨度和过期扫描仍拒绝；没有逐点时间时保持 header 的保守检收。地图方差、有效性和置信度按每格实际拟合支持的最早点采集时间老化。因此末点新鲜不能延长旧支持点的寿命，也没有按接收时间刷新地形。

去畸变采用的位姿质量也参与误差传播：以所有实际使用的插值位姿（含 header 锚点）的世界平移各轴方差上界、机体姿态最大轴方差的各向同性包络和速度/角速度上界，构造同一原始时间锚点的保守质量估计。这样扫描中段定位质量变差会增大地图方差，不会被 header 时刻的较小协方差掩盖。原始坐标和时间戳不受质量汇总影响。
